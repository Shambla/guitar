# Public 30-second previews

Put short preview clips here. These URLs are public on purpose.

Example for Off Kilter:

`off-kilter-grit-120-bpm-a-minor-30s.mp3`

Export tip: export first ~30 seconds from your DAW, or trim with:

```bash
ffmpeg -i full.mp3 -t 30 -c copy off-kilter-grit-120-bpm-a-minor-30s.mp3
```
